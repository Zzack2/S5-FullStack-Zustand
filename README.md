# Mini Tienda Reactiva — Código base del laboratorio

Proyecto base para el laboratorio de **useState, useMemo y useEffect**
(Desarrollo FullStack, Unidad 2).

## Instalación y ejecución

```bash
npm install
npm run dev
```

Luego abre la URL que Vite indique en la terminal (normalmente
`http://localhost:5173`).

## Dónde trabajar

Busca los comentarios `TODO` en estos archivos:

- `src/App.jsx` — Ejercicio 1 (useState), Ejercicio 3 (useEffect) y Ejercicio 4 (Zustand)
- `src/components/CarritoResumen.jsx` — Ejercicio 2 (useMemo) y Ejercicio 4 (Zustand)
- `src/components/Navbar.jsx` — Ejercicio 4 (Zustand)
- `src/store/useCarritoStore.js` — Ejercicio 4 (Zustand)

Sigue el **Manual de Laboratorio** entregado por el docente para el detalle
de cada ejercicio, el resultado esperado y los pasos a seguir.
